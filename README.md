




# 💼 Personal Portfolio

A **modern, responsive portfolio** showcasing my projects, skills, and experience. Includes smooth animations, dark mode support, and clean UI to highlight my work.

---

## 🌟 Features

- Responsive design for mobile, tablet, and desktop
- Dark and light theme support
- Smooth animations and interactive UI
- Projects showcase with links to GitHub and live demos
- Skills section highlighting tech stack
